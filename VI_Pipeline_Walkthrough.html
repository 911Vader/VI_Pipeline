02 · three entry points

One pipeline, three ways in

The entry point is auto-detected from the file extension. Each starting point joins the pipeline at a different stage, so already-processed data skips the work that has already been done.

A · FASTQ

Raw sequencing reads

.fastq.gz / .fq.gz

The full pipeline — alignment, variant calling, annotation, classification, and reporting.

Two files required: R1 (forward reads) and R2 (reverse reads).

Joins at Step 1 — runs everything
B · BAM / CRAM

Pre-aligned reads

.bam / .cram

Skips alignment and starts directly at variant calling with DeepVariant.

Must be coordinate-sorted against GRCh38. A missing .bai index is created automatically.

Joins at Step 7 — variant calling
C · VCF

Pre-called variants

.vcf / .vcf.gz

Skips alignment and calling, going straight to annotation. If the VCF already carries VEP CSQ, VEP is skipped too.

A .vcf.gz needs a tabix .tbi index — created automatically if missing.

Joins at Step 9 — annotation

Sixteen steps, start to report

The complete flow when starting from raw reads. Each card shows the tool and version, what goes in and comes out, the parameters that matter, and a plain-English account of what is happening and why.

Input detection & validation

input_router.pyvcf_validator.py

Reads the file extension and routes the job to the correct handler. For VCF inputs it runs six validation checks: the file exists, is a regular file, is readable, is not empty, has a tabix index if gzipped, and begins with ##fileformat=VCF.

It also checks whether the VCF already carries VEP CSQ annotation, so it never re-annotates work that is already done.

3

Alignment

BWA-MEM64 threads

Aligns each 150 bp Illumina paired-end read to the human reference. BWA-MEM is the gold-standard Illumina aligner: it finds exact-match seeds using the reference FM-index, then extends each alignment with Smith-Waterman. The SAM stream is piped straight to samtools.

  • Reference: GRCh38 genome.fa (BWA index v0.6.0)
  • Output: unsorted BAM stream → piped to next step
Why 64 threads, not 192
BWA-MEM has diminishing returns above ~64 threads because of internal synchronisation overhead. Running 192 threads delivered only ~46 effective cores at 4623% CPU — 64 threads is the efficient ceiling.
4

Coordinate sort

samtools sort

Sorts alignments by genomic coordinate (chromosome + position), reading directly from the BWA-MEM pipe. Every downstream tool requires coordinate order.

Out
HG001.sorted.bam
5

Fix mate information

samtools fixmate -m

Fills in mate-pair coordinate fields and adds the ms (mate score) tag. That tag is what duplicate marking uses to decide which read in a pair has the best quality — without it, markdup cannot work.

Often missed. This step is frequently left out of pipeline descriptions but is essential for correct duplicate marking.
6

Duplicate marking

samtools markdupremove_duplicates: true

Identifies PCR and optical duplicate read pairs — copies of the same original DNA molecule created during library prep. Duplicates inflate variant allele frequencies and cause false confidence. Using the ms tags from fixmate, markdup keeps the highest-quality read from each group and removes the rest.

  • Output: HG001.dedup.bam (106 GB) + .bai
  • Metrics: HG001.markdup.metrics.txt
Why samtools, not sambamba
sambamba 0.6.6 opens one temporary file per reference contig. GRCh38 has 195 contigs (chr1–22, X, Y, M plus unplaced scaffolds), which exceeded the system's open-file limit and caused failures.
7

Variant calling

DeepVariant 1.10.0WGS model · 192 shardsGPU-accelerated

Calls germline SNVs and small INDELs from the deduplicated BAM. DeepVariant is Google's deep-learning caller: instead of statistical models, it turns the read pileup at each candidate site into a three-channel image and classifies it with an Inception-v3 convolutional neural network trained on truth-labelled genomes. Runs from google/deepvariant:1.10.0-gpu when a GPU is available, google/deepvariant:1.10.0 otherwise (auto-detected via nvidia-smi).

Three internal phases
  • make_examples — builds pileup tensors across 192 parallel shards · ~22 min (CPU only)
  • call_variants — the CNN scores each tensor (hom-ref / het / hom-alt) · ~5–15 min on GPU, ~90 min on CPU
  • postprocess — writes a bgzipped, tabix-indexed VCF · brief
FILTER values
  • PASS — confident variant call
  • RefCall — reference supported (not a variant)
  • NoCall — insufficient evidence
GPU acceleration
Only call_variants (neural network inference) runs on the GPU — make_examples is always CPU-only. The pipeline auto-detects an NVIDIA GPU via nvidia-smi and selects the -gpu Docker image automatically (use_gpu: auto in settings.yaml). This can be forced on or off with use_gpu: true or false. On this server (RTX A6000, 48 GB VRAM), call_variants drops from ~90 minutes to ~5–15 minutes.
Out
HG001.dv.vcf.gz (121 MB) + .tbi
Run time
~45 min with GPU · ~2.5 hrs CPU-only

VCF normalisation

bcftools norm 1.22

Left-alignment shifts every INDEL to the leftmost valid reference position, so the same deletion looks identical no matter which tool produced it. Multiallelic splitting breaks records with several ALT alleles (e.g. A→T,G) into separate biallelic lines, which VEP and all downstream tools require.

  • Output: HG001.norm.vcf — 626 MB, 6,662,912 variants
  • FILTER split: PASS 4,765,053 · RefCall 1,411,409 · NoCall 486,450

10

VCF parsing

parser.py

Reads the VEP-annotated VCF into an internal Python data model. CSQ field names are read dynamically from the header — column order is never assumed. One primary transcript is chosen per variant by priority: canonical first, then most-severe consequence (from a ranked table of 40 consequence types), then the first transcript as a final tiebreak.

Multi-allelic records raise an error (they must be normalised first); missing optional scores are set to None rather than crashing.

Out
6,662,912 internal Variant objects

Gene-list filtering

filter_engine.pygene_list.txt · 316 genes

The primary clinical filter. A variant is kept if it meets any of: it sits in one of the 316 panel genes, it is ClinVar Pathogenic / Likely Pathogenic, or it passes the consequence + frequency rules below.

  • require_pass: true — only DeepVariant PASS variants
  • max_af: 0.01 — gnomAD frequency under 1% (rare only)
  • Tier 1 (always keep): stop_gained, frameshift, splice_acceptor / donor, start_lost, stop_lost
  • Tier 2 (keep unless strong benign): missense, splice_region, in-frame ins/del
  • Tier 3 (keep only if panel or ClinVar P/LP): synonymous, UTR, intron
  • Excluded: intergenic, upstream, downstream — and any ClinVar Benign / Likely Benign

Excluded

Applies standardised evidence criteria to label each retained variant as Pathogenic, Likely Pathogenic, VUS, Likely Benign, or Benign. Nine criteria are implemented in v1.0 — see the ACMG criteria table for the full colour-coded breakdown and thresholds.

06 · classification

ACMG / AMP 2015 criteria

The ACMG system is rule-based, not numeric: it fires named evidence criteria of different strengths, then combines them into a final call. These nine are implemented in v1.0.

Very Strong Strong Moderate Supporting Benign · stand-alone / strong Benign · supporting
CriterionStrengthWhat it checks
PVS1Pathogenic · Very StrongNull variant (stop / frameshift / essential splice) in a gene where loss-of-function is the disease mechanism — requires LOFTEE HC.
PS3Pathogenic · StrongClinVar P/LP with ≥2-star review status (well-established functional evidence, proxied).
PM2Pathogenic · ModerateAbsent or extremely rare in population databases — gnomAD AF < 0.01%.
PM4Pathogenic · ModerateProtein-length change — an in-frame insertion or deletion.
PP3Pathogenic · SupportingMultiple in-silico tools predict damaging: CADD >20 OR REVEL >0.75 OR SpliceAI >0.5 OR AlphaMissense >0.564.
BA1Benign · Stand-aloneAF >5% in any gnomAD population — definitively benign on its own.
BS1Benign · StrongAllele frequency higher than expected for a disease-causing variant.
BP4Benign · SupportingMultiple in-silico tools predict benign: REVEL <0.15 AND AlphaMissense <0.340.
BP7Benign · SupportingSynonymous variant with no predicted splice impact (SpliceAI <0.1).
How the rules combine. Pathogenic = (1 Very Strong + 1 Strong) or (1 Very Strong + 2 Moderate) or (2 Strong) etc. Likely Pathogenic = (1 Very Strong + 1 Moderate) or (1 Strong + 2 Moderate). Benign = (1 Stand-alone) or (2 Strong Benign). Likely Benign = (1 Strong Benign) or (2 Supporting Benign). Everything else is a VUS. Worked examples are in the How the tools work section.

08 · incident log

Six problems, and how each was fixed

Building the pipeline surfaced six concrete failures. Each is logged here with its symptom, root cause, and the exact change that resolved it.

01 DeepVariant timed out immediately

Symptom
DeepVariant timed out after 0.0 hour(s) — failed seconds after starting.
Root cause
timeout_hours: 0 was meant to mean "no timeout" but was passed straight into subprocess.run(timeout=0). In Python, timeout=0 means "expire in 0 seconds" — the process was killed before it could do anything.
Fix
Map 0 → None (Python's real "no timeout"). Changed in fastq_handler.py and bam_handler.py.

02 sambamba "too many open files"

Symptom
sambamba markdup failed with an OS error about open file descriptors.
Root cause
sambamba 0.6.6 opens one temporary file per reference contig. GRCh38 has 195 contigs (22 autosomes + X + Y + MT + 170 unplaced scaffolds), exceeding the file-descriptor limit even at low thread counts.
Fix
Switched markdup_tool from "sambamba" to "samtools", which has no such limit.

03 samtools markdup "no ms score tag"

Symptom
markdup produced no output, erroring about missing ms score tags.
Root cause
BWA-MEM was piped to sort, then straight to markdup. But markdup needs the ms tag to choose which duplicate to keep — and that tag is only added by samtools fixmate -m, which was missing.
Fix
Inserted samtools fixmate -m -O bam - - between sort and markdup — the correct three-step pipeline. Changed in fastq_handler.py.

04 VEP can't use VCF format — missing HTS module

Symptom
Cannot use format vcf without Bio::DB::HTS::Tabix module installed — VEP refused to start.
Root cause
Reverting VEP from 116 to 113 was done with --NO_HTSLIB, which also skipped installing the Bio::DB::HTS Perl XS bindings. The compiled HTS.so existed but not where Perl's @INC searches for XS extensions.
Fix
Placed the library at the path Perl expects:
/home/admin7995/ensembl-vep/auto/Bio/DB/HTS/HTS.so

05 VEP 116 cache download failed

Symptom
Unable to close datastream then tar: cannot open: No such file or directory.
Root cause
The ~24 GB 116_GRCh38 cache download failed mid-transfer. The incomplete archive was discarded, but INSTALL.pl still tried to extract it and found nothing.
Fix
Stayed on VEP 113 for all runs. The 116 upgrade is pending a successful cache re-download.

06 BWA using 192 threads inefficiently

Symptom
htop showed BWA-MEM at 4623% CPU (~46 cores), not 192 — while samtools sort consumed ~157 GB RAM.
Root cause
BWA-MEM's work partitioning saturates around 64 threads; extra threads contend for locks instead of doing parallel work, inflating RAM with no speed gain.
Fix
Reduced bwa_threads from 192 to 64.

10 · deep dive

How each tool works — alone and together

Each tool is a standalone technology with a specific job in the pipeline, where the output of one becomes the exact input of the next. Expand any tool to read the full explanation.

1

BWA-MEM

reads → aligned SAM›

What it is

An alignment tool answering one question: given this 150-character string of DNA bases, where in the 3.2-billion-base human genome does it come from?

How it works

The reference is pre-indexed with an FM-index (a compressed structure built on the Burrows-Wheeler Transform), turning the genome into a searchable lookup table. For each read BWA-MEM finds exact-match seeds, chains compatible seeds, then extends with Smith-Waterman dynamic programming. It emits a SAM record per read: chromosome, position, strand, CIGAR string, and mapping quality.

# CIGAR example 5M2I3M1D10M → 5 match · 2 bp insertion · 3 match · 1 bp deletion · 10 match

In this pipeline

Takes 89 GB of paired FASTQ and streams aligned reads (SAM) directly into samtools sort, running 64 threads. It cannot call variants — it only says "this read maps here," without interpreting what the differences mean.

2

samtools fixmate

repairs mate info · adds ms tag›

What it is

Repairs paired-end information that is missing or wrong when reads arrive from a pipe. In paired-end sequencing each fragment is read from both ends; the mate fields recording where the partner read maps need to be filled in.

The -m flag

Adds the ms (mate score) tag — a quality score for the mate read. Duplicate marking uses it to keep the best-quality pair from each duplicate group.

In this pipeline

Sits between sort and markdup. Without it, markdup fails with "no ms score tag" because it cannot tell which duplicate to keep.

3

samtools markdup

removes PCR duplicates›

What it is

Identifies and removes PCR duplicates — reads that are copies of the same original DNA molecule rather than independent observations. During library prep, fragments are amplified by PCR; multiple copies of the same fragment get sequenced as reads starting at the exact same position with the same sequence.

Why duplicates are bad

If 10 reads show a variant but 8 are PCR copies of 2 originals, there are really only 2 independent observations. Keeping duplicates inflates confidence and distorts allele balance.

In this pipeline

Takes the coordinate-sorted, mate-fixed BAM and produces a clean deduplicated BAM ready for calling, plus a metrics file with the duplication rate.

4

DeepVariant

pileups → genotype calls›

What it is

A variant caller that looks at how reads pile up at each genomic position and decides whether the difference from the reference is a real variant or sequencing noise.

How it differs from GATK

Traditional callers use probabilistic models — calculating the likelihood of each genotype from observed bases, qualities and error rates. Well understood, but they struggle in complex regions.

DeepVariant instead turns each candidate pileup into a three-channel "image" (encoding reference bases, read bases, and supporting quality) and feeds it to a convolutional neural network trained on thousands of truth-labelled genomes. The CNN classifies each site as 0/0 (hom-ref), 0/1 (het) or 1/1 (hom-alt). It learns the visual signatures of true variants versus artefacts, generalising to edge cases — strand bias, low complexity, repeats — that break statistical models.

The three phases & the FILTER values

make_examples builds the pileup images (massively parallel, 192 shards), call_variants runs the CNN, postprocess_variants writes the VCF. Each call is then PASS (confident variant), RefCall (confident reference), or NoCall (ambiguous).

GPU acceleration

make_examples is CPU-only by design — it reads the BAM and builds tensor images, a task that parallelises well across many cores but has no GPU path. call_variants, however, is pure neural network inference: batches of pileup images fed through a convolutional network. This is exactly what GPUs are built for. The pipeline detects an available NVIDIA GPU via nvidia-smi and automatically selects the google/deepvariant:1.10.0-gpu Docker image with --gpus all. On this server (RTX A6000, 48 GB VRAM), call_variants completes in ~5–15 minutes instead of ~90 minutes — a 10–20× speedup for that step. Total end-to-end time drops from ~2.5 hours to ~45 minutes. The setting use_gpu in settings.yaml accepts auto (default), true, or false.

5

bcftools norm

canonical VCF representation›

What it is

Standardises VCF files so the same variant is always written the same way. Callers can represent one variant in multiple forms; norm enforces a canonical one.

Left-alignment

Shifts INDEL representations to the leftmost valid reference position. Without it, the same deletion can appear at several positions across different VCFs, so they fail to match during benchmarking or database lookup.

Multiallelic splitting

before chr1 100 . A T,G . PASS after chr1 100 . A T . PASS chr1 100 . A G . PASS

VEP and the ACMG classifier can only handle one ALT allele at a time. In this pipeline norm takes the 121 MB DeepVariant VCF and produces the 626 MB normalised VCF — larger because multiallelic records are now split across lines.

6

VEP

variants → biological meaning›

What it is

The Variant Effect Predictor from Ensembl. Given genomic positions, it answers "what does this variant do to the biology?" using the reference annotation — gene positions, exon boundaries, transcript structures and protein sequences.

How it works

For each variant VEP looks up overlapping transcripts, determines the consequence by where the variant falls (exon → coding consequence; exon/intron boundary → splice; intron → intronic; near a gene → up/downstream), translates codon changes to amino-acid changes, computes HGVS naming, looks up gnomAD frequencies, and calls each plugin. Most genes have several transcripts; the pipeline reports the Ensembl canonical as primary, with most-severe consequence as tiebreaker. All of it lands in a single pipe-separated CSQ INFO field, one entry per transcript.

In this pipeline

The heaviest step — 6.6 million variants across 192 forks, producing a 13 GB annotated VCF.

8

ACMG classification logic

rules, not a score›

ACMG does not produce a number. It fires named criteria of different strengths and combines them by rule.

Worked example — pathogenic

Loss-of-function variant in BRCA1 → PVS1 fires (LOFTEE HC confirms it) Not present in gnomAD → PM2 fires CADD 38 · REVEL 0.92 · AlphaMissense 0.81 → PP3 fires PVS1 + PM2 + PP3 = Pathogenic

Glossary

Every term used across the pipeline, defined in plain language.

SNV / SNP
Single Nucleotide Variant/Polymorphism — a single base change (e.g. A→G at one position).
INDEL
Insertion or Deletion — bases added to or removed from the genome.
WGS
Whole Genome Sequencing — sequencing the entire ~3.2 billion base genome.
GRCh38
The current human reference genome assembly (Genome Reference Consortium, build 38).
FASTQ
Raw sequencing file format: read sequence + a quality score per base.
BAM
Binary Alignment Map — compressed file of reads aligned to the reference.
SAM
Sequence Alignment Map — the text version of BAM.
VCF
Variant Call Format — text file listing variants, positions, alleles and quality.
bgzip
Block gzip — compression allowing random access, required for tabix indexing.
tabix
Tool that builds a .tbi index for bgzipped files, enabling fast region lookup.
CIGAR
Compact Idiosyncratic Gapped Alignment Report — encodes how a read aligns (matches, gaps, clips).
Read
A single sequenced DNA fragment (~150 bases for Illumina).
Paired-end
Sequencing both ends of the same DNA fragment (R1 and R2).
Coverage / Depth
How many reads cover a position. 30× = 30 reads on average.
PCR duplicate
A copy of the same molecule from library amplification — not an independent observation.
Allele
A version of the sequence at a location (e.g. reference A, alternate G).
Heterozygous
One copy carries the variant (0/1) — one allele from each parent.
Homozygous
Both copies carry the variant (1/1).
VAF
Variant Allele Frequency — fraction of reads supporting the alternate allele.
PASS / RefCall / NoCall
Caller verdicts: passed all filters · confident reference · insufficient data.
Consequence
The functional effect of a variant on a transcript (missense, frameshift, etc.).
HGVS
Human Genome Variation Society nomenclature — standardised variant names (c.1234A>G, p.Asn412Ser).
Canonical transcript
The single representative transcript Ensembl chooses per gene.
LoF
Loss of Function — a variant that destroys the protein product (stop, frameshift, essential splice).
gnomAD
Genome Aggregation Database — population allele frequencies from >730,000 individuals.
ClinVar
NCBI database of clinically interpreted variants.
ClinGen
Clinical Genome Resource — curated gene-disease validity evidence.
ACMG
American College of Medical Genetics — published the standard classification guidelines.
Pathogenic / Likely Pathogenic
Disease-causing · high probability (>90%) of being disease-causing.
VUS
Variant of Uncertain Significance — insufficient evidence to classify.
Benign / Likely Benign
Not disease-causing · high probability of being benign.
Precision
Of all variants the pipeline called, the fraction that were real.
Recall / Sensitivity
Of all real variants that exist, the fraction the pipeline found.
F1 score
Harmonic mean of precision and recall — one metric balancing both.
TP / FP / FN
True positive · false positive · false negative.
GIAB
Genome in a Bottle — NIST consortium providing reference samples with known truth variants.
hap.py / vcfeval
The standard benchmarking tool · RTG Tools' comparison engine for complex variant matching.
Ti/Tv ratio
Transition:transversion ratio — QC metric, expected ~2.1 for WGS SNPs.
Het/Hom ratio
Heterozygous:homozygous variant ratio — expected ~1.5 for WGS.
CADD
Combined Annotation Dependent Depletion — integrative deleteriousness score.
REVEL
Rare Exome Variant Ensemble Learner — missense pathogenicity ensemble.
SpliceAI
Deep-learning tool predicting variant impact on RNA splicing.
AlphaMissense
DeepMind tool predicting missense effect via protein-structure modelling.
LOFTEE · HC / LC
Loss-of-Function Transcript Effect Estimator — classifies LoF as High or Low Confidence.
SIFT / PolyPhen-2
Conservation- and structure-based missense predictors.
PVS1 / PM2 / PP3
ACMG pathogenic criteria: null variant (Very Strong) · rare in population (Moderate) · in-silico damaging (Supporting).
BA1
ACMG criterion: AF >5% in population — definitively benign (stand-alone).
Phred score
Quality score: Phred 20 = 1% error, Phred 30 = 0.1%. Used for base quality and CADD.
Docker
Container platform packaging a tool + dependencies into a portable image.
Shard
An independent parallel worker — 192 shards = 192 processes running at once.
CSQ
VEP's INFO field holding all annotation data per transcript.
Left-alignment / Multiallelic
Shifting an INDEL to the leftmost valid position · a record with more than one ALT allele.
VI_Pipeline
A whole-genome sequencing pipeline for germline variant interpretation — FASTQ, BAM or VCF in; a ranked, ACMG-classified clinical report out.
