1 Overview

3 First-Time Setup

Run once before the first analysis. Locates all tools and resources, then writes config/paths.yaml.

  1. Run setup
    python cli.py --setup

    Prints [OK], [WARN], or [FAIL] for every tool and resource. Required items marked [FAIL] must be resolved before analysis.

  2. Fix missing resources

    Open config/paths.yaml, fill in the path: field for any missing resource, then re-run:

    python cli.py --setup --force
  3. Confirm success
      All required checks passed.
  Paths saved to: config/paths.yaml
Noteconfig/paths.yaml holds machine-specific absolute paths. It is not committed to git and should not be shared between machines.

9 Pipeline Steps — Start to Report (FASTQ path)

1

Input detection & validation input_router.py

Reads file extension, routes to the correct handler. For VCF inputs: verifies file exists, is readable, has a tabix index if gzipped, and begins with ##fileformat=VCF. Detects CSQ annotation to skip VEP on pre-annotated files.

2

FASTQ synchronisation seqkit / fastp

Ensures R1 and R2 reads are correctly paired and in the same order. Orphaned read pairs would cause alignment failures downstream.

Out
.r1.synced.fastq.gz · .r2.synced.fastq.gz
3

Alignment minibwa v0.2 · 32 threads

Aligns paired-end reads to GRCh38 using minibwa (a compact BWA-MEM2 replacement). The SAM stream is piped directly to samtools. minibwa saturates at ~32 threads — higher counts add lock contention with no throughput gain.

Out
SAM stream → piped to sort
4

Coordinate sort samtools sort

Sorts alignments by genomic position. Every downstream tool requires coordinate order.

Out
<id>.sorted.bam
5

Fix mate information samtools fixmate -m

Fills in mate-pair coordinate fields and adds the ms (mate score) tag. Duplicate marking uses this tag to choose which read in a pair to keep — without it, markdup fails. This step is frequently omitted in pipeline descriptions but is essential.

6

Duplicate marking samtools markdup

Identifies and removes PCR duplicates — copies of the same original DNA molecule from library amplification. Duplicates inflate variant allele frequencies and cause false confidence.

Out
<id>.dedup.bam (106 GB)
Also
.markdup.metrics.txt · .flagstat.txt
7

BAM QC samtools flagstat

Runs immediately after BAM creation, before the multi-hour DeepVariant step. Logs ERROR if total reads = 0; logs WARNING if mapped rate < 70% (wrong reference or contamination).

8

Variant calling DeepVariant 1.10.0 · 192 shards · GPU

Calls germline SNVs and small INDELs. Instead of statistical models, DeepVariant turns each read pileup into a three-channel image and classifies it with an Inception-v3 CNN trained on truth-labelled genomes. Three internal phases: make_examples (CPU, builds pileup tensors) → call_variants (GPU, CNN inference, ~5–15 min vs ~90 min CPU) → postprocess (writes VCF).

Out
<id>.dv.vcf.gz (121 MB)
Time
~45 min GPU · ~2.5 hrs CPU
9

VCF normalisation bcftools norm

Left-alignment shifts INDELs to the leftmost valid position. Multiallelic splitting breaks records like A→T,G into two biallelic lines — required by VEP and all downstream tools.

Out
<id>.norm.vcf.gz — 626 MB · 6,662,912 variants
10

VEP annotation Ensembl VEP 113 · 192 forks · offline

For every variant: determines affected genes/transcripts, consequence type, HGVS names, gnomAD frequencies, and scores from six plugins (CADD, REVEL, SpliceAI, AlphaMissense, LOFTEE, ClinVar). Runs offline against the homo_sapiens_113_GRCh38 cache.

Out
<id>.norm.vep.vcf.gz — 13 GB
Time
~2 hrs
11

VCF parsing parser.py

Reads the annotated VCF into internal Python objects. CSQ field names are read dynamically from the header — column order is never assumed. One primary transcript chosen per variant: canonical first, then most-severe consequence, then first transcript.

Out
6,662,912 Variant objects
12

ClinGen gene lookup clingen.py

Cross-references each variant's gene against ClinGen Gene Validity (Definitive / Strong / Moderate / Limited / No Known Disease Relationship). 552,898 variants matched a curated gene.

13

Filtering filter_engine.py · 316 gene panel

Keeps a variant if it meets any of: in gene panel, ClinVar P/LP, or passes consequence + frequency rules.

  • require_pass: true — DeepVariant PASS only
  • max_af: 0.01 — gnomAD AF under 1%
  • Tier 1 (always keep): stop_gained, frameshift, splice_acceptor/donor, start_lost, stop_lost
  • Tier 2: missense, splice_region, in-frame ins/del
  • Excluded: intergenic, ClinVar Benign/Likely Benign
Retained
319,728 (4.8%)
Excluded
6,343,184 (95.2%)
14

ACMG / AMP classification acmg/classifier.py · ACMG/AMP 2015

Applies nine evidence criteria to classify each variant as Pathogenic / Likely Pathogenic / VUS / Likely Benign / Benign. See the ACMG Criteria section for full details.

15

Ranking ranker.py

Sorts by composite score: ACMG classification (Pathogenic highest) → ClinGen tier → consequence severity → in-silico scores → ClinVar review status.

16

Report generation reporting/

Writes PDF, XLSX, TSV, JSON, and run log from the ranked variant set.

10 VEP Plugins — Six Dimensions of Evidence

Each plugin scores a variant from a different angle. Alone none is definitive; together they provide the multi-tool consensus ACMG PP3 and BP4 require.

CADD
Combined Annotation Dependent Depletion

A Phred-scaled score integrating 60+ annotations to rank deleteriousness. Every possible SNV in the genome is pre-scored; INDELs from gnomAD.

Threshold>20 = top 1% · >30 = top 0.1%
ACMGContributes to PP3 (damaging)
REVEL
Rare Exome Variant Ensemble Learner

Ensemble missense score combining 13 tools (SIFT, PolyPhen, FATHMM etc.) via random forest. Covers all possible missense variants.

Threshold>0.75 pathogenic · <0.15 benign · 0.15–0.75 gray zone
ACMGPP3 (damaging) / BP4 (benign)
SpliceAI
Illumina / Stanford deep-learning

Predicts RNA splicing impact — four delta scores (acceptor/donor gain/loss). Detects cryptic splice variants invisible to consequence-based annotation.

Thresholdmax delta >0.5 = likely splice-altering
ACMGPP3 / BP7 (no splice impact at <0.1)
AlphaMissense
Google DeepMind · AlphaFold-based

Models amino-acid change effect on protein structure and function using the AlphaFold structure model.

Threshold>0.564 pathogenic · <0.340 benign
ACMGPP3 / BP4
LOFTEE
Loss-of-Function Transcript Effect Estimator

Classifies LoF variants as High-confidence (HC) or Low-confidence (LC), filtering false positives in last 5% of transcript, non-conserved regions, NMD-insensitive transcripts.

GatesPVS1 fires only on HC LoF variants
ClinVar
NCBI · custom annotation

NCBI's database of clinically-interpreted variants. Extracts CLNSIG, CLNREVSTAT, CLNDN (disease name) into the CSQ field.

GatesPS3: P/LP with ≥2-star review (proxied)
NoteClinVar IS embedded inside CSQ (confirmed on HG001 run)

11 ACMG / AMP 2015 Criteria

Rule-based, not numeric. Nine criteria implemented in v1.0:

CriterionStrengthWhat it checks
PVS1Pathogenic Very StrongNull variant (stop / frameshift / essential splice) in a LoF gene — requires LOFTEE HC
PS3Pathogenic StrongClinVar P/LP with ≥2-star review status
PM2Pathogenic ModerateAbsent or extremely rare in gnomAD (AF < 0.01%)
PM4Pathogenic ModerateProtein-length change (in-frame insertion or deletion)
PP3Pathogenic SupportingMultiple in-silico tools predict damaging: CADD>20 OR REVEL>0.75 OR SpliceAI>0.5 OR AlphaMissense>0.564
BA1Benign Stand-aloneAF >5% in any gnomAD population — definitively benign alone
BS1Benign StrongAF higher than expected for a disease-causing variant
BP4Benign SupportingMultiple tools predict benign: REVEL <0.15 AND AlphaMissense <0.340
BP7Benign SupportingSynonymous variant with no predicted splice impact (SpliceAI <0.1)
Combination rulesPathogenic = PVS1 + 1 Strong; or PVS1 + 2 Moderate; or 2 Strong. Likely Pathogenic = PVS1 + 1 Moderate; or 1 Strong + 2 Moderate. Benign = 1 Stand-alone; or 2 Strong Benign. Everything else is VUS.

Worked example — Pathogenic

Loss-of-function in BRCA1
  → PVS1 (LOFTEE HC confirmed)
Not present in gnomAD
  → PM2
CADD 38 · REVEL 0.92 · AlphaMissense 0.81
  → PP3
PVS1 + PM2 + PP3 = Pathogenic

12 Runtime Errors INCIDENT LOG

Six concrete failures encountered while building and running the pipeline. Each is logged with its symptom, root cause, and the exact fix.

01 DeepVariant timed out immediately

Symptom
DeepVariant timed out after 0.0 hour(s) — failed seconds after starting
Root cause
timeout_hours: 0 was meant to mean "no timeout" but was passed directly into subprocess.run(timeout=0). In Python, timeout=0 means "expire in zero seconds" — the process was killed before it could do anything.
Fix
Map 0 → None (Python's real "no timeout"). Changed in fastq_handler.py and bam_handler.py.

02 sambamba "too many open files"

Symptom
sambamba markdup failed with an OS error about open file descriptors.
Root cause
sambamba 0.6.6 opens one temporary file per reference contig. GRCh38 has 195 contigs (22 autosomes + X + Y + MT + 170 unplaced scaffolds), exceeding the system file-descriptor limit even at low thread counts.
Fix
Switched markdup_tool from "sambamba" to "samtools", which has no such limit.

03 samtools markdup "no ms score tag"

Symptom
markdup produced no output, erroring about missing ms score tags.
Root cause
BWA-MEM was piped to sort, then straight to markdup. markdup needs the ms tag to choose which duplicate to keep — that tag is only added by samtools fixmate -m, which was missing from the pipeline.
Fix
Inserted samtools fixmate -m -O bam - - between sort and markdup — the correct three-step pipeline.

04 VEP refused to start — missing HTS module

Symptom
Cannot use format vcf without Bio::DB::HTS::Tabix module installed
Root cause
Reverting VEP from 116 to 113 was done with --NO_HTSLIB, which skipped installing the Bio::DB::HTS Perl XS bindings. The compiled HTS.so existed but not at the path Perl's @INC searches for XS extensions.
Fix
Placed the library at: /home/admin7995/ensembl-vep/auto/Bio/DB/HTS/HTS.so

05 VEP 116 cache download failed

Symptom
Unable to close datastream then tar: cannot open: No such file or directory
Root cause
The ~24 GB 116_GRCh38 cache download failed mid-transfer. The incomplete archive was discarded, but INSTALL.pl still tried to extract it and found nothing.
Fix
Stayed on VEP 113 for all production runs. The 116 upgrade is pending a successful full cache re-download.

06 BWA using 192 threads inefficiently

Symptom
htop showed BWA-MEM at 4623% CPU (~46 effective cores), not 192 — while samtools sort consumed ~157 GB RAM.
Root cause
BWA-MEM's work partitioning saturates around 64 threads. Extra threads contend for internal locks rather than doing parallel work, inflating RAM with no speed gain.
Fix
Reduced bwa_threads from 192 to 64. (Subsequently switched to minibwa which saturates at ~32.)

13 Code Bugs Found & Fixed

BUG A PP3 rule — REVEL gray zone missing

File
analysis/acmg/rules.py — eval_PP3(), lines 289–293
Problem
In eval_PP3, any REVEL score below the pathogenic threshold (0.75) set g1_ben = True, actively canceling a damaging vote from CADD in the same correlated group. Scores between 0.15 and 0.75 are a gray zone — they carry no signal in either direction. A gray-zone REVEL score should be neutral, not cancel evidence from another tool. The sister function eval_BP4 already had correct three-zone logic; PP3 was asymmetric.
Impact
Variants with CADD >20 + REVEL 0.50 (gray) + SpliceAI >0.5 had PP3 suppressed: REVEL canceled CADD's group vote, leaving only SpliceAI — one group, not two — so PP3 = False (should be True). Missense variants were being silently under-classified.
  if variant.revel_score is not None:
      if variant.revel_score >= t["revel_pathogenic"]:
          g1_dam = True
-     else:
-         g1_ben = True
+     elif variant.revel_score <= t["revel_benign"]:
+         g1_ben = True
+     # Gray zone (0.15–0.75): neutral — must not cancel a CADD damaging vote

BUG B VEP completion check — header-only file treated as complete

File
analysis/annotator.py — _output_is_complete()
Problem
Returned True if the VCF had a CSQ header line, even if VEP crashed after writing headers but before writing any variant records. On the next pipeline run, VEP would be skipped and the parser would receive an empty VCF — zero variants, no error.
- return any("CSQ" in line for line in header_lines)
+ has_csq_header = any("CSQ" in line for line in header_lines)
+ has_data = any(not line.startswith("#") for line in lines)
+ return has_csq_header and has_data

BUG C ClinVar filter — substring matching caused false positives

File
analysis/filter_engine.py
Problem
ClinVar deprioritization used substring matching on CLNSIG. Values like Conflicting_interpretations_of_pathogenicity contain the substring "pathogenic" and could accidentally match configured exclusion terms. Slash-separated multi-significance values (e.g. Benign/Likely_benign) were matched as a single string instead of individual components.
+ components = {
+     part.strip().lower().replace("_", " ")
+     for part in variant.clinvar_significance.replace(",", "/").split("/")
+     if part.strip()
+ }
+ if components & exclude_sigs:   # exact set intersection
+     # deprioritize

BUG D Test failures — 6 failures in test_fastq_handler.py

File
tests/analysis/upstream/test_fastq_handler.py
Root cause 1
shutil.which("pigz") was not mocked. Since pigz is installed on the server, _run_minibwa_align took the shell path (single bash command with set -o pipefail), collapsing per-process exit codes. Tests expected separate "minibwa alignment failed" vs "samtools sort failed" messages but got identical errors in shell mode.
Root cause 2
_run_flagstat and _run_markdup were not mocked in full-pipeline tests — they tried to run real samtools/sambamba and failed before reaching the mocked steps.
Fix
Added patch("analysis.upstream.fastq_handler.shutil.which", return_value=None) to force the Popen code path. Added _run_flagstat and _run_markdup mocks to all full-pipeline test contexts.

Problem
test_missing_error_contains_bwa_index_command asserted "bwa index" in message — but after the aligner switch to minibwa, the error message changed to redirect users to minibwa_index_prefix instead.
Fix
Renamed test to test_missing_error_redirects_to_minibwa; updated assertion to check for "minibwa_index_prefix" in message.

BUG F Test: check_all_tools hardcoded expected keys

File
tests/setup/test_tool_checker.py

test_check_all_tools_returns_all_keys had a hardcoded expected_keys set that was missing "minibwa" and "samtools", added when the aligner was replaced.
Fix
Added both keys to the expected set: {"docker", "conda", "python", "nextflow", "vep", "bcftools", "bgzip", "tabix", "minibwa", "samtools"}.

Improvement
Resume integrity — BAM and VCF validation before skipping steps
fastq_handler.py · bam_handler.py

Resume logic previously only checked Path.exists() and size > 0. A BAM truncated mid-write by OOM or SIGKILL appeared valid — DeepVariant would spend hours on corrupt input.

Added _bam_is_intact() running samtools quickcheck (validates EOF block) and _vcf_has_records() verifying at least one non-header data line exists. All four resume checkpoints now use these validators.

Improvement
BAM QC — samtools flagstat before DeepVariant
fastq_handler.py · bam_handler.py

No QC check existed before the multi-hour DeepVariant step. A misaligned BAM would only be discovered after DeepVariant failed. Added _run_flagstat(): logs ERROR if total reads = 0; WARNING if mapped rate < 70%.

Improvement
BAM sort-order validation before DeepVariant
bam_handler.py

DeepVariant requires a coordinate-sorted BAM. If a user provided an unsorted BAM, DeepVariant would fail with a cryptic error deep into the run. Added _check_bam_sort_order() reading the @HD SO: tag and raising a clear error immediately.

Improvement
LOFTEE — consolidated DEGRADED MODE warning
analysis/annotator.py

When LOFTEE helper files were missing, each missing file generated a separate warning at different points in the code. Replaced with a single consolidated DEGRADED MODE warning listing all missing helpers and their impact on HC/LC classification accuracy.

Improvement
ACMG classifier — exception tracking and decision trace
analysis/acmg/classifier.py · analysis/parser.py

When an ACMG rule function raised an exception it was silently skipped with no audit trail. Added variant.acmg_skipped_rules (list of rule codes that errored) and variant.decision_trace["acmg"] dict recording: rules evaluated, triggered, skipped, classification, confidence, and all scores used. Available in JSON export.

Improvement
Per-variant decision trace
filter_engine.py · acmg/classifier.py · parser.py

Added variant.decision_trace dict. The filter engine populates decision_trace["filter"] (outcome, reason, consequence tier, gnomAD AF, gene list membership). The ACMG classifier populates decision_trace["acmg"]. Both are available in the JSON export for every variant.

Improvement
Excluded variants visible in filter summary
analysis/filter_engine.py

Added top_excluded to the filter summary dict: the first 20 excluded variants with coordinates, gene, consequence, gnomAD AF, and exclusion reason — visible in the run log without reading thousands of log lines.

Improvement
bcftools norm timeout — configurable, default disabled
vcf_normalizer.py · config/settings.yaml

Previous hardcoded 2-hour timeout caused large WGS VCFs to abort. Now read from settings.yaml as bcftools.norm_timeout_hours. Default is 0 (no timeout), safe because bcftools will either succeed or fail on its own.

Improvement

reporting/__init__.py · json_export.py · pdf_report.py · run_log.py · spreadsheet.py · tsv_export.py

PIPELINE_VERSION = "1.0.0" was hardcoded independently in three files. Added it as a single constant to reporting/__init__.py; all other files now import from there. XLSX Info sheet and TSV comment line now also embed the version.

18 Glossary

SNV / SNP
Single Nucleotide Variant/Polymorphism — a single base change (e.g. A→G).
INDEL
Insertion or deletion of bases in the genome.
WGS
Whole Genome Sequencing — sequencing the entire ~3.2 billion base genome.
GRCh38
Current human reference genome assembly (build 38).
FASTQ
Raw sequencing file: read sequence + per-base quality scores.
BAM / SAM
Binary/text format of reads aligned to the reference.
VCF
Variant Call Format — lists variants, positions, alleles, and quality.
bgzip / tabix
Block-gzip compression + indexed random-access for VCF/BED files.
CSQ
VEP's INFO field holding all annotation data per transcript.
CIGAR
Encodes how a read aligns (matches, insertions, deletions, clips).
Paired-end
Sequencing both ends of the same DNA fragment (R1 and R2).
Coverage / Depth
Number of reads covering a position. 30× = 30 reads on average.
PCR duplicate
A copy of the same molecule from library amplification — not independent.
VAF
Variant Allele Frequency — fraction of reads supporting the alternate allele.
PASS / RefCall / NoCall
DeepVariant caller verdicts.
Consequence
Functional effect of a variant on a transcript (missense, frameshift, etc.).
HGVS
Standardised variant names: c.1234A>G, p.Asn412Ser.
Canonical transcript
The single representative transcript Ensembl designates per gene.
LoF
Loss of Function — destroys the protein product (stop, frameshift, essential splice).
gnomAD
Genome Aggregation Database — allele frequencies from >730,000 individuals.
ClinVar
NCBI database of clinically interpreted variants.
ClinGen
Clinical Genome Resource — curated gene-disease validity evidence (Definitive / Strong / Moderate / Limited).
ACMG / AMP
American College of Medical Genetics — published the standard classification guidelines (2015).
Pathogenic / Likely Pathogenic
Disease-causing / high probability (>90%) of being disease-causing.
VUS
Variant of Uncertain Significance — insufficient evidence to classify.
Benign / Likely Benign
Not disease-causing / high probability of being benign.
Precision
Of all variants called, the fraction that were real.
Recall / Sensitivity
Of all real variants, the fraction the pipeline found.
F1 score
Harmonic mean of precision and recall.
GIAB
Genome in a Bottle — NIST consortium providing reference samples with known truth variants.
Ti/Tv ratio
Transition:transversion ratio — QC metric, expected ~2.1 for WGS SNPs.
CADD
Combined Annotation Dependent Depletion — integrative deleteriousness score (Phred-scaled).
REVEL
Rare Exome Variant Ensemble Learner — missense pathogenicity ensemble score.
SpliceAI
Deep-learning tool predicting variant impact on RNA splicing.
AlphaMissense
DeepMind tool predicting missense effect via protein-structure modelling.
LOFTEE · HC / LC
Loss-of-Function Transcript Effect Estimator — classifies LoF as High or Low Confidence.
PVS1 / PM2 / PP3
ACMG pathogenic criteria: null variant (Very Strong) · rare in population (Moderate) · in-silico damaging (Supporting).
BA1 / BS1
ACMG benign criteria: AF >5% (stand-alone) · AF higher than expected (strong).
Left-alignment
Shifting an INDEL to the leftmost valid reference position for canonical representation.
Multiallelic
A VCF record with more than one ALT allele — must be split before annotation.
Docker
Container platform packaging a tool + dependencies into a portable image.
Shard
An independent parallel worker — 192 shards = 192 processes at once.
ms tag
Mate-score BAM tag added by samtools fixmate — required by samtools markdup.
